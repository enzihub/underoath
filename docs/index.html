Four spells

Every fight is about chaining these four. The spells are named Q, W, E and R, and keys 1 to 4 cast them by default. You can rebind them in Settings. All screenshots are from the real browser build.

QShadow Strike

A bolt of dark energy in an arc. It damages everything in the cone and marks enemies for Void Rush.

WProtective Aura

Three spheres orbit the hero for five seconds and detonate when an enemy touches them.

EVoid Rush

Dash straight to a marked enemy and hit it on arrival. Good for closing the gap or escaping a pack.

RDarkfall

The big one. Pulls every nearby enemy into the hero and hits them all for heavy damage.

How to play

A short sandbox run. This is a 2025 prototype, so there is no story or ending yet.

I · Explore

Right-click the ground to move through the glade. Three camps wait for you: an ember warden, a pack of shade raptors and two stone brutes.

II · Fight

Press G to attack the closest enemy. Spend mana on the four spells. Shadow Strike marks enemies, and Void Rush dashes to a marked one.

III · Clear the camps

Clear all three camps. Stone brutes split into shards when they fall, and cleared camps come back after four to five minutes.

Run it yourself

The game is a static Next.js export, so any static file host can serve it. You need Node.js 18 or newer.

# get the code and install
git clone https://github.com/enzihub/underoath.git
cd underoath
npm install

# play locally with hot reload on http://localhost:8080
npm run dev

# or build the static game into dist/ and serve it
npm run build
npm start
